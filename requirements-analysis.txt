# Dependencias del análisis de calidad de datos (src/analysis)
#
# Requiere Python 3.12 o superior. El analizador abre XML descargado de Internet
# con `xml.etree.ElementTree`, y la defensa contra la expansion de entidades
# (billion laughs) la pone el interprete: en 3.12 el ataque rebota con «limit on
# input amplification factor breached», y en versiones anteriores no.
# Instalar: python -m venv .venv-analysis && .venv-analysis\Scripts\pip install -r requirements-analysis.txt
#
# Comprobar antes de lanzar un análisis:
#   python -m src.analysis --check-deps
# Aborta si falta cualquier lector, en vez de generar un informe a medias. Los dos
# informes generados sin openpyxl (9 de agosto 14:56 y 13 de agosto) archivaron
# cientos de XLSX como «no analizados», y el segundo llegó a producción.
frictionless[excel]>=5.19,<6
# Explícito, aunque frictionless[excel] ya lo arrastre: depender de él por vía
# transitiva es exactamente cómo se perdió. Es el lector de XLSX, el formato con
# más distribuciones del catálogo después de CSV.
openpyxl>=3.1
# El otro lector de Excel, explícito por el mismo motivo. `excel.py` decide el
# formato por magic bytes, no por la extensión: un archivo declarado XLSX cuyo
# contenido sea un OLE2 de Excel 97-2003 se lee con xlrd. El catálogo no tiene
# ninguno ahora mismo, y precisamente por eso su ausencia no se notaría hasta el
# día que lo tenga.
xlrd>=2.0
pyshp>=2.3
Pillow>=10.0
icalendar>=5.0
filetype>=1.2
geojson>=3.0
charset-normalizer>=3.0
requests>=2.31
pytest>=8.0
